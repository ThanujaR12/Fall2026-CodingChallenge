# Tech Stack & Architecture (input for /speckit.plan)

Use this for every feature's `/speckit.plan`. Only build the parts the current feature needs.

## Stack

| Layer | Choice | Why |
|-------|--------|-----|
| Frontend | Vite + React + **TypeScript** | Top rubric tier (with a component library) |
| Component library | shadcn/ui + Tailwind CSS (alternative: Mantine) | Top rubric tier; easy to theme to match `design/` |
| Routing | React Router | Standard, simple |
| Server state | TanStack Query | Caching, optimistic updates, infinite scroll |
| Backend | Node.js + **Express** + TypeScript | Top backend rubric tier |
| Database | MongoDB Atlas (free tier) + Mongoose | Top data tier; flexible for nested collaborators |
| Auth | bcrypt password hashing + JWT | Simple, well-documented |
| Validation | zod (shared request schemas) | Clear errors at the edge |
| Images | Pixabay API, called **only from the backend** | Keeps the API key secret |
| Palette extraction | Server-side library (e.g., node-vibrant) when an item is saved | Avoids browser canvas/CORS issues |
| Testing | Vitest + Supertest (backend) | Covers auth, permissions, item CRUD |
| Tooling | ESLint + Prettier | Consistent style |

## Data model

**User**
- username (unique), email (unique), passwordHash, createdAt

**Collection**
- name, description, owner (User)
- members: [{ user (User), role: "editor" | "viewer" }]
- visibility: "private" | "public"
- shareToken (random, nullable), shareEnabled (bool)
- palette: [hex strings] (derived)
- createdAt, updatedAt

**SavedItem**
- collection (Collection), addedBy (User)
- source: "pixabay", sourceId
- imageUrls: { preview, web, large }, pageUrl, tags, creatorName
- title, note
- colors: [hex strings]
- createdAt, updatedAt
- unique index on (collection, sourceId)

**Notification** (Feature 3)
- recipient (User), actor (User), collection, action: "added" | "edited" | "removed", itemTitle, read (bool), createdAt

## API endpoints (base path `/api`)

Auth
- `POST /auth/register`
- `POST /auth/login`
- `GET  /auth/me`

Search
- `GET /search/images?q=&page=&color=` — proxies Pixabay, caches identical queries

Collections
- `GET    /collections` — mine + shared with me
- `POST   /collections`
- `GET    /collections/:id`
- `PATCH  /collections/:id` — rename/description/visibility (owner; editors: description only)
- `DELETE /collections/:id` — owner only

Items
- `POST   /collections/:id/items` — save image
- `PATCH  /collections/:id/items/:itemId` — edit title/note
- `DELETE /collections/:id/items/:itemId` — remove

Sharing & members
- `POST   /collections/:id/share` — enable link, returns URL
- `DELETE /collections/:id/share` — disable/revoke link
- `GET    /shared/:shareToken` — public read-only view
- `POST   /collections/:id/members` — invite { usernameOrEmail, role }
- `PATCH  /collections/:id/members/:userId` — change role
- `DELETE /collections/:id/members/:userId` — remove member / leave

Explore & notifications (Feature 3)
- `GET   /explore` — public collections
- `GET   /notifications`
- `PATCH /notifications/:id/read`

Status codes: 200/201 success, 204 delete, 400 validation, 401 not logged in, 403 no permission, 404 not found, 409 duplicate, 500 unexpected.
Error shape: `{ "error": { "code": "COLLECTION_NOT_FOUND", "message": "..." } }`

Document every endpoint in `server/API.md` (method, path, auth, body, responses, example).

## Pixabay notes

- Get a free key at https://pixabay.com/api/docs/
- Use safe search.
- Read the API docs' rules on caching results and on hotlinking images, and follow them. Show image credit (creator name + link to the Pixabay page).

## Design reference

- Set design tokens once (Tailwind theme / CSS variables) and reuse them.
- Collection page theming uses the palette as an accent layered on top of the base design tokens.
